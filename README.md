## 这是什么

一份独立的经济报告，讲 1949 年以来中国经济的位置与来路：经济总量的世界位置、
各国 GDP 对比、经济与产业的 14 项指标、两岸 GDP 对比、关键节点对照表，
以及作者本人的一份解释。

- **年份** 1949–2026（数据年截至可得的最新一年，图上逐处标注）
- **对照** 中国大陆与美国、日本、德国、法国、英国、俄罗斯、印度、韩国、新加坡，
  以及台湾地区
- **口径** GDP（现价美元）与 PPP（购买力平价）两套并列，**不跨口径连线**

页面还附一份**数据来源与口径**，逐项列明出处与边界。

## 如何更新

报告由 [gov-capacity-report](https://github.com/insseek/gov-capacity-report)
的经济专题产出（`src/econ.py`）。更新流程：

```bash
# 1. 在主仓库重新生成
cd ../gov-capacity-report
make report          # 或 python src/econ.py

# 2. 同步到本仓库（复制为 index.html，校验后提交并推送）
cd ../china-economic-development-report
./sync.sh
```

`sync.sh` 是本地脚本、不入库（见 `.gitignore`）。它会先校验**报告可离线打开**
（资源加载型外链为 0）、体积合理、关键内容齐备，再复制并提交——
避免同步出一份空壳或残缺的页面。
